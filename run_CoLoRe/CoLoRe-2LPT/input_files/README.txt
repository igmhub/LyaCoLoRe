These are the input files used for the CoLoRe-2LPT boxes for DESI DR2 FS (Ruiz-Herrera+2026):
- Pk_Abacus_Cosmology_z0.txt is the input power spectrum. It matches the AbacusSummit cosmology at z=0 i.e. mean estimates of the TT,TE,EE+lowE+lensing likelihood chains from the Planck 2018 results. 
- Bz_clustering.txt, Tz_clustering.txt, Nz_qso_130618_2_colore1_hZs.txt: These are the bias, threshold and dN/dzdOmega respectively as a function of redshift (first column). The bias and threshold come from the empirical relations derived from CoLoRe-2LPT snapshot version (Ruiz-Herrera+2026).
